# FAKESTORE Detector — Ultimate Showcase Edition

A visually enhanced Streamlit competition prototype for reviewing warning signs in online stores.

## Run on macOS
```bash
python3 -m pip install -r requirements.txt
python3 -m streamlit run app.py
```

## Modules
- Overview command centre with visual feature cards and session metrics
- Store audit with URL heuristics and an eight-point shopper checklist
- Store verification checklist with progress tracking
- Side-by-side URL signal comparison
- Scam pattern learning library
- Downloadable audit report

## Limitations
This is a heuristic prototype. It does not query live WHOIS/domain-age services, browse submitted websites, validate business registrations, verify payment processors, or retrieve independent customer reviews. Checklist inputs are user-reported. Scores are warning indicators, not fraud probabilities or safety certifications.
